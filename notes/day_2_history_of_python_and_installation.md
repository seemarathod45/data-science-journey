# History of Python
   ## Created by Guido van Rossum, who started working on it in the late 1980s. The first public version came out in 1991.
   ### The name does not come from the snake. It comes from a British comedy show, Monty Python's Flying Circus, which Guido liked.
   ### Python 2 was the older version. Python 3 (released 2008) is the one used today. Python 2 is no longer supported, so you only learn Python 3.
  ## It became popular because the code is easy to read, and later because Data Science and AI libraries were built for it.

  # Installation of Python

## What it means: Your computer does not understand Python by default. When you install Python, you install the interpreter (the program that reads your code line by line, which you learned about in Day 1).

 ### Key points:

## Download from the official site, python.org.
### During install, tick "Add Python to PATH". PATH tells your computer where to find Python, so the command python works in the terminal. Beginners often forget this and then get "python is not recognized" errors.
# Check it worked by typing python --version in the terminal. You already did this, so yours is installed correctly.
