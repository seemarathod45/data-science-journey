# Day 1 - Python Introduction

## What I learned today

### 1. What is Python?
Python is a general-purpose, high-level, object-oriented and interpreted language.

### 2. What is programming?
Programming means writing instructions for a computer to do a task.

### 3. What is a high-level language?
A high-level language is easy for humans to read and write.

### 4. What is an interpreter?
An interpreter runs the code line by line.

### 5. What is object-oriented?
Object-oriented means the code is divided into objects and classes.
